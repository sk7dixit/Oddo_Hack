# Traveloop

A collaborative travel planning platform.

## Team Branches
| Member | Module | Branch |
|--------|--------|--------|
| Member 1 | Auth | `auth-feature` |
| Member 2 | Trip | `trip-feature` |
| Member 3 | Budget | `budget-feature` |
| Member 4 | UI + Admin | `ui-feature` / `admin-feature` |

## Setup

```bash
# Pull latest develop before starting
git pull origin develop

# Frontend
cd frontend && npm install && npm run dev

# Backend
cd backend && npm install && npm run dev
```

## Common Rules
1. Do NOT rename folders or change structure
2. Use TypeScript everywhere
3. Keep reusable components separate
4. Use REST API naming conventions
5. Do NOT modify another member's folders
6. Push only to your assigned branch
